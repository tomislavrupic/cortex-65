# Factory patches

Select a patch in the rack and press **Load**. Loading keeps the current play/pause and mute state. Save a personal combination before replacing its settings. All six patches use eight voices; exact random trajectories vary between runs.

| Patch | Character | Motion |
| --- | --- | --- |
| Orbital Rain | Minor-key rain, irregular droplets and long tails | Head Orbit .018 Hz, about56seconds per lap |
| Cortical Thunder | Broad Brainstorm bursts across both hemispheres | Wide stereo, every4seconds on average |
| Deep Current | Continuous low fifths bed with slow regional swells | Head Orbit .012 Hz, about83seconds per lap |
| Glass Canopy | Sparse C-major rain with a wide octave range | Head Orbit .026 Hz, about38seconds per lap |
| Slow Bloom | Warm C-major waves, long decay and release | Head Orbit .01 Hz,100seconds per lap |
| D Major Drift | Original screenshot patch | Pulses off; click a region or press E |

Presets use the same validated JSON format as your own saved files. They do not reset the evolving phase state or start audio automatically. Head Orbit supplies analytic headphone cues; it is separate from binaural beat pairs.
